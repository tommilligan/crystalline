# crystalline

[![CI](https://github.com/tommilligan/crystalline/actions/workflows/ci.yml/badge.svg)](https://github.com/tommilligan/crystalline/actions/workflows/ci.yml)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)

This tool helps you make good decisions - efficiently.

It guides you (or a team) through making decisions in a set, sequential process:

- Problem clarification
- Idea generation
- Option evaluation
- Picking the final outcome

This simplifies each stage, by focusing on the key skills uniquely required at each step. For example, creativity is *needed* for idea generation, but disruptive during evaluation.

## Origin

This tool is an adaptation of the Crystal Ball decision-making tool, [developed by](https://www.linkedin.com/posts/activity-7305992104365678592-QWPq) Bob Darius (GSK/Sanofi) and originally inspired by Dr. Edward de Bono's *Six Thinking Hats*.
It started life as a physical whiteboard exercise (see the example below) - this repo turns it into an interactive, collaborative tool.

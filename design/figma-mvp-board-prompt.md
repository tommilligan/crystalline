Design Crystal Ball, a single-page team decision tool (Six Thinking Hats), as a five-column board, desktop/projector-first with a laptop fallback. All columns stay visible; one is "current phase," set via a persistent tab/dropdown selector — any phase clickable anytime, nothing locked.

1. Situation (red-tinted) — one large problem-statement textarea. Optional advisory countdown (15-20min); never auto-advances anything.
2. Options (blue-tinted) — fast idea list: text field + Enter-to-add for rapid live transcription. Simple list/cards, inline edit/remove. Cloud shape optional.
3. Evaluation (grey) — per option, short Enabler + Blocker fields, shown as an extension of that option's row so they stay visually together.
4. Costs/Benefits (white) — per option, six 1-5 inputs: People/Time/Money (cost) + Quality/Service/Price (benefit). A "1=bad, 5=good" legend must be permanently visible (biggest confusion point in the original tool). Read-only computed total per option; ranking/highlight once several options are scored.
5. Decision (green) — option picker (linked, not free text), Countermeasure text, always-visible Dissent text, Approved By + Date, and a separate deliberate "Sign" button with an irreversible-action confirmation.

Signed state: every input disabled, phase nav hidden, only Export (PNG) and Clone remain — style as a distinct locked mode.

Also design: "New board from template" entry screen; empty-state hints in Evaluation/Scoring when no options exist ("add options first, or jump in anyway"); a narrower/tabbed layout for laptop widths.

Out of scope: auth, multiplayer presence, voting UI, audit log, PDF export, custom templates.
